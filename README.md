
# Event-Driven Architecture

This is the companion repository for the planned book *Event-Driven Architecture*.

The code is meant to illustrate concepts from the book. It may be lacking in other aspects that are not relevant to that goal.


## Repository map

- `chapter0x/` for chapters that refer to source code, you'll find the example code in the folder with the chapter number.
- `event-driven-auctions/` is a complete, working example of an event-driven application, which is occasionally referred to in the book. You'll find a description in [event-driven-auctions/README.md](event-driven-auctions/README.md).



## Status

This is work in progress. Source code will be avaible by the publishing date of the book.
